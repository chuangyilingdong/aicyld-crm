# AICYLD CRM 一页纸 SOP

> 系统：https://crm.aicyld.com  
> 规则：一个客户一条人员，一次成交一条商机，聊一次一条沟通记录。  
> 状态只看商机阶段，下一步只看商机“下次跟进时间”。

## A（建联 / 首聊）

- [ ] 建联后 10 分钟内：新建**人员**，填姓名、手机/微信、来源渠道；开发人=A。
- [ ] 同时新建**商机**，命名 `客户名-意向产品`，阶段=新线索，负责人=A。
- [ ] 首聊当天：新建**第 1 条沟通记录**，轮次=1，填渠道、沟通内容、客户反馈、本轮结果。
- [ ] 商机阶段改成“首轮沟通”，填**下次跟进时间**。
- [ ] 判断有意向：
  - [ ] 商机阶段=待交接
  - [ ] 商机负责人=B
  - [ ] 交接摘要写清：需求 / 预算 / 决策人 / 顾虑 / 已承诺事项
- [ ] 工作流会给 B 建“接手跟进”任务；B 没收到就口头提醒。

## B（成交）

- [ ] 接手 24 小时内完成第 2 轮沟通。
- [ ] 每聊一次，当天建一条**沟通记录**：轮次递增，渠道、内容、客户反馈、本轮结果都要填。
- [ ] 每次沟通后更新商机：
  - [ ] 当前轮次
  - [ ] 下次跟进时间
  - [ ] 阶段（二轮跟进 / 方案报价 / 成交 / 流失）
- [ ] 成交当天：阶段=成交，填金额、成交日期。
- [ ] 流失：阶段=流失，填流失原因。

## 主管

- [ ] 每天看“我的待跟进”里的逾期记录，问一句“今天能约上吗？”
- [ ] 每周看“二轮以上未成交”：轮次多但没成交的，抽听/复盘。
- [ ] 每周看渠道仪表盘：哪个渠道线索多、成交多，预算往哪挪。

## 沟通记录模板

```
客户说了什么：
顾虑/异议：
我方回应：
下一步：
```

## 三条红线

1. 聊完当天不录，等于没聊。
2. 商机没有“下次跟进时间”，等于没人管。
3. 交接只改商机负责人；人员没有负责人字段，B 从“我的待跟进”看商机。
