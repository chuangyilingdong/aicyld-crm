# 客户跟进一页纸 SOP

> 系统：https://crm.aicyld.com
> 规则：一个客户一条，聊一次一条，提醒放客户，交接改负责人。

## A（建联 / 首聊）

- [ ] 新建**客户**：姓名、微信号、来源渠道；当前负责人=A；客户状态=新客户。
- [ ] 打开客户 → **沟通记录** → 添加第 1 轮：标题“第1轮-日期”、轮次 1、沟通时间、沟通人 A、沟通内容、本轮结果。
- [ ] 回客户字段：最后沟通时间=今天；下次提醒日期=3 天后；提醒内容写清楚。**有日期就代表提醒开着。**
- [ ] 判断有意向：
  - [ ] 当前负责人改成 B
  - [ ] 告诉 B 打开“我的客户-员工B”
  - [ ] 不需要改其他字段，也不需要工作流

## B（持续跟进 / 成交）

- [ ] 打开客户，先看“沟通记录”里的历史。
- [ ] 联系完：
  - [ ] 新增沟通记录：标题“第N轮-日期”、轮次+1、沟通时间、沟通人 B、内容、结果
  - [ ] 最后沟通时间=今天
  - [ ] 延长：改下次提醒日期 + 提醒内容；关闭：清空下次提醒日期
- [ ] 第 3、4 轮重复。
- [ ] 不用填当前轮次；沟通记录最上面一条就是最新轮次。
- [ ] 有下次提醒日期=提醒开着；清空=关闭；改日期=延长。
- [ ] 成交：客户状态=已成交。流失：客户状态=流失。

## 主管

- [ ] 每天看“待提醒”：有日期的都在列表里，今天/更早的在最上面，问一句“今天能联系吗？”
- [ ] 每周看“全部客户”：跟进中/已成交/流失的数量。
- [ ] 轮次多但没成交的客户，抽看沟通记录。

## 沟通内容模板

```
客户说了什么：
顾虑/异议：
我方回应：
下一步：
```

## 三条红线

1. 聊完当天不录，等于没聊。
2. 客户没有下次提醒日期，等于没人管。
3. 交接只改客户的“当前负责人”，B 才能在自己的视图里看到。

## 手机号

手机可选。如果提示“输入有效的电话号码”：先选国家 **China (+86)**，再输入 11 位手机号；不想填就留空，用微信号联系。
