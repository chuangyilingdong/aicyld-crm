# 客户跟进一页纸 SOP

> 系统：https://crm.aicyld.com
> 规则：一个客户一条，聊一次一条，提醒放客户，交接改负责人。

## 刘羽驰（建联 / 首聊）

- [ ] 新建**客户**：姓名、微信号、来源渠道；当前负责人=刘羽驰；当前阶段=可逼单。
- [ ] 打开客户 → 在 **沟通记录** 表格点 **“+”** 新增（关联客户自动填当前客户）：标题可留空、沟通时间、沟通人=刘羽驰、沟通内容；轮次和标题会自动生成。
- [ ] 回客户字段：下次提醒日期=3 天后 09:00（可精确到分钟）；提醒内容写清楚。**有日期就代表提醒开着。** 最后沟通时间自动同步，不用填。
- [ ] 判断有意向：
  - [ ] 当前负责人改成 影子 11
  - [ ] 系统把客户放回“待提醒”（已完成重置为否，原有日期/自定义提醒内容保留；没有提醒或还是旧自动文案时才写“【新指派给 影子 11】请及时联系客户”，日期为空补今天 09:00）
  - [ ] 影子 11 打开“待提醒”就能在最上面看到；也可以打开“我的客户-影子 11”
  - [ ] 不需要改其他字段，也不需要工作流

## 影子 11（持续跟进 / 成交）

- [ ] 打开客户，先看客户页“沟通记录”表里的历史（只显示这个客户的记录）。
- [ ] 联系完：
  - [ ] 点表格里的 **“+”** 新增沟通记录（自动关联当前客户）：标题可留空、沟通时间、沟通人=影子 11、沟通内容；轮次和标题自动生成
  - [ ] 如果“今日与关注”里有这个客户，也可以直接在业务概览面板点“完成”标记提醒
  - [ ] 延长：改下次提醒日期时间 + 提醒内容；关闭：清空下次提醒日期
- [ ] 第 3、4 轮重复。
- [ ] 不用填轮次和标题；保存后自动是下一轮，标题自动生成“第N轮-日期”。
- [ ] 有下次提醒日期时间=提醒开着；清空=关闭；改日期=延长。
- [ ] 成交：当前阶段=保证金缴纳（后续待培训/待招生/开课中）。暂缓/流失：当前阶段=在考虑。

## 主管

- [ ] 每天先看侧栏“待提醒”的红色数字和“业务概览”卡片；点开总览看阶段、负责人、趋势和需要关注的客户。
- [ ] 点“无下次提醒”数字看名单，优先给这些客户补下次提醒。
- [ ] “今日与关注”里今天/逾期的行可以直接点“完成”；需要周报时点“周报”复制，或点“导出”下载 CSV。
- [ ] 每天看“待提醒”：有日期的都在列表里，今天/更早的在最上面，问一句“今天能联系吗？”
- [ ] 每周看“全部客户”：各阶段数量（可逼单/已电话/已演示/在考虑/保证金缴纳及以后）。
- [ ] 轮次多但没成交的客户，点客户列表里的 **“N轮”** 链接，看每轮的标题和内容。
- [ ] 需要横向对比所有机构时，打开侧栏 **沟通总览**：一行一家机构、一列一轮；点格子看全文。
- [ ] 补沟通：直接点矩阵里的空白 `＋`；或点开详情后点“新增下一轮”；已填的格子点“编辑”可改日期/沟通人/内容。
- [ ] 重要或需要特别注意的沟通，勾 **★ 重点沟通**；矩阵里会变成琥珀色 + ★。
- [ ] 需要看全国经销商分布时，打开侧栏 **经销商地图**：点“放置旗帜”再点地图，填名称/标签/颜色；拖动调整位置。旗帜独立于客户数据，不关联客户记录。
- [ ] 一次标多个城市：保存后会自动保持放置模式，继续点地图即可；Esc 退出。同城多面旗帜会显示城市数字，点数字可飞到城市并筛选列表；删除后 6 秒内可撤销。

## 沟通内容模板

```
客户说了什么：
顾虑/异议：
我方回应：
下一步：
```

## 三条红线

1. 聊完当天不录，等于没聊。
2. 客户没有下次提醒日期，等于没人管。
3. 交接只改客户的“当前负责人”，对方才能在自己的视图里看到。

## 手机号

手机可选。字段默认国家已设为 **China (+86)**，直接输入 11 位手机号即可；下拉列表仍能看到其他国家（Twenty 原生行为），但不用手动选。不想填就留空，用微信号联系。
