# 客户跟进 CRM（简化版）

> **一个客户一条记录；每一轮沟通一条记录；提醒放在客户上。**
> 不做商机、阶段、销售管道、交接工作流。

## 1. 两个对象

| 对象 | 一条记录代表 | 怎么用 |
|---|---|---|
| **客户**（People 改名） | 一个客户 | 存联系方式、负责人、状态、提醒 |
| **沟通记录**（自定义） | 一轮沟通 | 在客户页的“沟通记录”里添加，按轮次倒序查看，最新一轮在最上面 |

侧边栏保留“全部客户”和“待提醒”两个入口；沟通记录从客户详情页进入，不单独放在侧边栏。点“全部客户”总是回到全部客户视图，不会停在待提醒。

## 2. 客户字段

标准字段：姓名、手机（可选）。**邮箱已从创建表单和客户详情页隐藏**（字段本身保留在数据模型里，不影响 Twenty 原生功能，但界面不再显示）。

自定义字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| 微信号 | 文本 | 客户微信/企微号 |
| 来源渠道 | 单选 | 抖音 / 小红书 / 视频号 / 微信 / 转介绍 / 线下 / 官网 / 闲鱼 / QQ群 |
| 当前负责人 | 单选 | 刘羽驰 / 影子 11 / 张镇峰 / 员工D（员工D先占位） |
| 当前阶段 | 单选 | 可逼单 / 已电话 / 已演示 / 在考虑 / 保证金缴纳 / 待培训 / 待招生 / 开课中 |
| 下次提醒日期 | 日期时间 | 具体到分钟，例如“11月8日 14:30”；原来的纯日期提醒统一迁到当天 09:00 |
| 提醒内容 | 文本 | 例如“再次联系客户，确认报价” |
| 已完成 | 布尔 | 在“待提醒”里勾“是”即移出待提醒；改下次提醒日期/内容或换负责人会自动重置为“否”；换负责人不会改原有日期/自定义内容 |
| 最后沟通时间 | 日期时间 | **自动同步**：取该客户“最高轮次”那条沟通记录的沟通时间（同轮次取最新日期），不用手填；创建客户表单里不显示。新增/修改/删除沟通记录时数据库触发器立即更新 |
| 沟通轮次 | 链接（自动） | 自动显示“N轮”，点击在当前页弹大窗口显示每轮标题+完整内容（Ctrl/中键打开原生卡片页）；新增/修改/删除沟通记录时数据库触发器立即更新，不用手填 |
| 备注 | 长文本 | 客户背景、偏好、禁忌；直接显示内容，不需要标题 |

> **备注不再用带标题的 Notes 标签页**：客户页的“备注”标签已移除，备注统一用客户上的“备注”字段，打开客户直接显示内容，没有标题需要填。原来记在 Notes 里的内容已迁到这个字段。
>
> 客户列表里的“备注”列也改成显示这个字段的内容（不再是 Notes 的“未命名”标题）；备注内容较长时列表里会截断，点开客户看全文。
>
> **没有“提醒开关”字段。** 有下次提醒日期 = 提醒开着；清空日期 = 关闭；改日期 = 延长。“已完成”只是把已处理的提醒从“待提醒”视图隐藏，不影响提醒日期；换负责人、改日期或改提醒内容时会自动重置为“否”，重新回到待提醒。**换负责人只重置“已完成”，客户原有的下次提醒日期和自定义提醒内容都会保留**；只有提醒为空、或内容还是旧的“【新指派给…】”自动文案时，才会补写新的指派提醒。
>
> **提醒时间精确到分钟**：选完日期后可以再选时/分（例如“11月8日 14:30”），统一按 **Asia/Shanghai** 时区显示和排序。2026-11-08 迁移前的纯日期提醒已统一补成当天 09:00。

## 3. 沟通记录字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 标题 | 文本 | 可留空；留空时自动生成“第N轮-日期”，例如“第4轮-10月12日” |
| 关联客户 | 关系 → 客户 | 必填；从客户页添加时会自动关联 |
| 轮次 | 数字 | **自动计算**：该客户已有最大轮次 +1；新增表单里不显示 |
| 沟通时间 | 日期时间 | 实际沟通时间 |
| 沟通人 | 单选 | 刘羽驰 / 影子 11 / 张镇峰 / 员工D |
| 沟通内容 | 长文本 | 客户说了什么、顾虑、下一步；打开沟通记录时置顶显示全文 |
| 重点沟通 | 布尔 | 勾选后这一轮在沟通总览里用琥珀色背景 + ★ 标记；原生记录页也能改 |

> 新增沟通记录时只需要填：关联客户（自动）、沟通时间、沟通人、沟通内容。**标题可留空**，保存时会自动生成“第N轮-日期”；**轮次自动算**（已有 3 轮就填 4），新增表单里没有轮次字段。这个逻辑由服务器数据库触发器 `set_communication_round` 完成，每分钟的同步脚本会自动创建/修复它。
>
> **“本轮结果”字段已停用**（历史数据保留在数据库里，界面不再显示）；每轮的状态不再单独记录，客户的整体情况看客户列表的“当前阶段”。
>
> 标题忘记填也能改：打开沟通记录详情页，**“标题”字段可编辑**。
>
> **客户详情页的“沟通记录”是一张只显示当前客户记录的表**（记录页布局里的 FIELD 组件，显示模式 TABLE；视图带“当前记录”筛选）。新增时点表格里的 **“+”**，关联客户会自动填成当前客户。
>
> 客户上的“沟通记录”关系已设为只读：表格不再有“编辑关系”按钮，客户列表不再显示“沟通记录”列。全工作区记录的选择器不会再出现。
>
> 客户列表看 **“沟通轮次”** 列（例如“10轮”）。点这个链接会**在当前页弹出大窗口**（不跳转、不新开标签页），按**轮次倒序**（第3轮、第2轮、第1轮）显示每一轮的标题和**完整沟通内容**；弹窗只点右上角 × 关闭（点遮罩、按 Esc 不会关闭，避免误触）。
>
> 这个弹窗是自定义脚本实现的：服务器 `/opt/twenty/crm-rounds-panel.js`（仓库里是 `nginx/crm-rounds-panel.js`），由 nginx 注入到页面；Ctrl/中键点击仍会打开原生“客户沟通记录（卡片）”页作为兜底。Twenty 升级后如果弹窗不出现，先检查这个脚本和 nginx 的 `sub_filter` 配置。
>
> 原生卡片页只保留“标题 + 沟通内容”两列；弹窗数据从该视图读取，所以两处内容一致。

其他字段（关联商机、渠道、客户反馈、意向等级、附件）已隐藏；“本轮结果”已停用，保持表单简单。

> 客户上不再有“当前轮次”字段；看沟通记录最上面一条的轮次即可（最新在上）。

## 5. 每天怎么用

### 新建客户 + 第 1 轮

1. 客户 → 创建：填姓名、微信号、来源渠道；当前负责人选 **刘羽驰**。
2. 打开客户 → 在“沟通记录”表格点 **“+”** 新增（关联客户自动填当前客户）：标题可留空（自动生成“第1轮-日期”）、沟通时间、沟通人选 **刘羽驰**、沟通内容。
3. 回到客户字段：下次提醒日期=3 天后 09:00（可具体到分钟）；提醒内容写清楚要做什么。**有日期就代表提醒开着。** 最后沟通时间会自动同步，不用填。

### 交接给影子 11

1. 客户字段：当前负责人从 **刘羽驰** 改成 **影子 11**。
2. 系统会把客户重新放回“待提醒”：如果客户原来有下次提醒日期和自定义提醒内容，**原样保留**；只有原来没有提醒、或提醒内容还是旧的“【新指派给…】”自动文案时，才写“【新指派给 影子 11】请及时联系客户”，日期为空时补今天 09:00。
3. 影子 11 打开“待提醒”，这个客户会排在最上面（今天/逾期在最前）；也可以打开“我的客户-影子 11”看全部客户。
4. 不需要工作流，也不需要改其他字段。

### 影子 11 持续跟进

1. 打开客户，先看客户页“沟通记录”表里的历史（只显示这个客户的记录）。
2. 联系完：
   - 点表格里的 **“+”** 新增一条沟通记录（自动关联当前客户）：标题可留空、沟通时间、沟通人选 **影子 11**、沟通内容；轮次自动算
   - 延长提醒：改下次提醒日期 + 提醒内容；关闭提醒：清空下次提醒日期
3. 第 3、4 轮重复。
4. 成交：当前阶段=保证金缴纳（后续待培训/待招生/开课中）；暂缓/流失：当前阶段=在考虑。

### 每天提醒

打开“待提醒”视图，按日期时间从早到晚看：

- 有下次提醒日期的客户都在列表里；今天/更早的排在最上面
- 点开客户 → 看提醒内容和沟通历史
- 联系完：延长就改下次日期；关闭就清空日期
- **只想把提醒从列表移走、不想改日期**：把“已完成”勾成“是”，客户就从待提醒隐藏；日期和内容还在。以后改日期/内容或换负责人会自动变回“否”，重新出现（换负责人不会改原有日期和自定义内容）
- **批量清理**：勾选多行 → 编辑“已完成”为“是”

## 6. 规则

- **一个客户一条记录**：不要给同一个人建多条客户。
- **轮次自动算**：新增沟通记录时按该客户已有最大轮次 +1；标题留空自动生成“第N轮-日期”，不用手填。
- **聊一次一条沟通记录**：不要把所有轮次写进一个字段。
- **提醒只看“下次提醒日期（精确到分钟）”**：有日期=提醒开着；清空=关闭；改日期=延长。
- **最后沟通时间和沟通轮次自动同步**：新增/修改/删除沟通记录时，数据库触发器会**立即**更新客户的最后沟通时间和“N轮”；每分钟的同步脚本只做兜底。最后沟通时间取“最高轮次”那条记录的时间（同轮次取最新日期），所以即使某一轮日期录错，也不会把最后沟通时间顶掉。
- **客户页会自动刷新**：在客户页新增/删除沟通记录后，沟通记录表格一变化，页面会在约 2 秒内自动刷新，“沟通轮次”和“最后沟通时间”立刻更新。若记录是从别的页面添加、或由其他同事添加，当前客户页不会自动刷新，手动刷新即可。
- **交接只改“当前负责人”**：系统会把客户重新放回“待提醒”（“已完成”重置为否），但**保留原有提醒日期和自定义内容**；只有没有提醒或还是旧的自动指派文案时，才写“【新指派给 某人】请及时联系客户”，日期为空时补今天 09:00。对方打开“待提醒”就能看到。
- **手机可选**：字段默认国家已设为 **China (+86)**，直接输入 11 位手机号即可；下拉列表里仍然能看到其他国家（Twenty 原生行为），但不用再手动选。不想填就留空，用微信号联系。

## 10. 提醒强化与业务概览（2026-11-08）

### 侧栏提醒

- “待提醒”右侧红色数字 = **逾期 + 今天**的未完成提醒；为 0 时不显示，超过 99 显示 `99+`。
- 有逾期时“待提醒”文字和图标变红；只有今天到期时变橙色。
- 浏览器标签标题会加 `(N) ` 前缀，切到别的标签也能看到。
- 每 60 秒刷新一次；切换回 CRM 页面时也会刷新。
- 逾期超过 3 天会在数字提示和列表里加重标红。
- 口径：`nextReminderAt` 非空、`已完成 = false`；逾期 = 已过提醒时间；今天 = 现在到当天 24:00（Asia/Shanghai）。

### 侧栏“业务概览”卡片（工作区下方）

- 位置：“待提醒”下面，宽度跟随侧栏；侧栏折叠时自动隐藏，只留角标圆点。
- 显示：待处理、逾期、本周沟通、30 天未联系、更新时间。
- 点整张卡片或“查看完整总览 →”会在**当前页**打开大面板，不跳转、不新开标签页。
- 口径：
  - 待处理 = 逾期 + 今天；
  - 本周 = 周一 00:00（Asia/Shanghai）起；
  - 30 天未联系 = 最后沟通超过 30 天，或从未沟通且创建超过 7 天。

### 业务总览面板

- **负责人筛选**：顶部“全部 / 刘羽驰 / 影子 11 / 张镇峰 / 员工D / 未分配”切换，KPI、阶段、趋势、轮次、来源、今日与关注一起切换；负责人工作量表始终显示全公司对比，并高亮当前选中的人。
- KPI：客户总数（副标题显示本周新增）、**无下次提醒**（没有提醒 = 没人管，**点击可看名单**）、待处理提醒（逾期/今天/未来拆分）、本周沟通、30 天未联系。
- 阶段分布（可逼单 → 开课中）底部显示“已演示及以上 / 保证金及以上”人数和占比（按当前阶段估算，不是历史漏斗）。
- 来源渠道图例里带“保 N”，表示该渠道里处于保证金缴纳及以后的人数。
- **今日与关注**：先列今天和已逾期的提醒（显示具体时间、负责人、提醒内容），再列 30 天未联系的客户；最多 5 条 + “去待提醒查看”。
- **直接完成**：今天/逾期的每一行右侧有“完成”按钮，点一下就把该客户标记为已完成，角标和面板立即更新，不用跳到待提醒。
- **无下次提醒名单**：点第二个 KPI，面板切换到名单视图，按最后沟通从久到近列出；点客户名可直接去补提醒，左上角“返回总览”。
- **导出 / 周报**：面板右上角“导出”下载当前筛选范围的 CSV（姓名/手机/微信号/负责人/阶段/来源/提醒/轮次）；“周报”把本周汇总复制到剪贴板，可直接粘贴到飞书/微信。
- 打开面板时才拉取全部客户和沟通记录（每页 100 条，自动翻页），前端聚合；面板内可手动刷新，打开期间每 60 秒自动刷新。
- 在 CRM 里新增/修改数据、勾“已完成”、加沟通记录后，脚本会拦截 GraphQL mutation，约 1-2 秒后自动刷新角标、卡片和面板，不用等 60 秒。
- 数据按**当前登录账号的可见范围**统计；未登录时面板提示先登录。

### 桌面提醒（浏览器通知）

- 页面**右下角**有悬浮的“🔔 开启提醒”按钮；打开“业务概览”面板后，右上角第一个按钮和面板顶部提示条也能开启。点一下授权；授权后按钮显示“桌面提醒已开”，再点可发一条测试通知。
- 到点后浏览器会弹系统通知，显示时间、客户、负责人和提醒内容；点通知直接打开该客户。

## 11. 沟通总览（2026-11-08）

### 入口

侧栏“待提醒”下面新增 **沟通总览**（表格图标）。点它打开所有机构的沟通矩阵，不跳转页面。

### 布局

- **行 = 一家机构**：左侧固定列显示机构名、当前负责人、当前阶段、最后沟通时间。
- **列 = 第 1 轮、第 2 轮…**：按当前所有客户的最大轮次自动生成，例如“轮次 1–4”；这不是上限，客户新增第 5 轮后会自动出现第 5 列（最多显示 20 列）。列头显示“X 家 · Y 条”。
- **单元格**：日期（月/日）、沟通人（带颜色点）、沟通内容前 3 行；最新一轮左侧有蓝色竖线。
- 勾了“重点沟通”的轮次用**琥珀色背景 + ★**，顶部统计会显示“重点 N 条”，工具栏有图例。
- 没有某轮记录的格子显示 `＋`，**点击可直接给这家机构补这一轮**。
- 单元格右上角 `×N` 表示同一轮有多条记录（显示最新那条）。

### 操作

- 顶部搜索框：按机构名或沟通内容搜索。
- 负责人筛选：全部 / 刘羽驰 / 影子 11 / 张镇峰 / 员工D / 未分配。
- “只看有沟通”：隐藏没有任何沟通记录的机构。
- 点任意有内容的格子：弹出详情，显示完整沟通内容、日期、沟通人；可“编辑”“新增下一轮”“复制内容”或“打开客户”；**只点右上角 × 关闭**（点遮罩、按 Esc 不会关闭）。
- 详情里点“编辑”：可修改这一轮的沟通时间、沟通人、沟通内容和“重点沟通”标记；如果标题是自动生成的“第N轮-月日”，会随日期一起更新；保存后最后沟通时间/轮次同步刷新。
- 新增/编辑表单里都有 **★ 重点沟通（需要特别注意）** 勾选项；原生沟通记录页的“字段”里也有“重点沟通”，两处都能改。
- 沟通总览、业务概览、详情、新增/编辑表单都**只通过右上角 × 关闭**；点空白和按 Esc 都不会关闭，避免误触丢输入；表单保存成功后会自动关闭。
- 点空白格子的 `＋`：弹出“新增沟通”表单，默认沟通时间=现在、沟通人=客户当前负责人；填写内容保存后，格子立即填上，标题自动生成，客户的最后沟通时间和轮次同步更新。
- 详情里的“新增下一轮”：直接给这家机构加“当前最大轮次+1”的沟通。
- 表头和第一列固定；轮次多时横向滚动，机构多时纵向滚动。
- 每次打开会重置筛选，默认显示全部机构；顶部“刷新”重新拉取（缓存 60 秒）。
- 新增沟通走 `createCommunicationRecord`，只写 `content.markdown`，服务端自动生成标题和 tiptap；保存后矩阵和侧栏角标/卡片都会刷新。
