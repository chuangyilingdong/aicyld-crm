# 客户跟进 CRM（简化版）

> **一个客户一条记录；每一轮沟通一条记录；提醒放在客户上。**
> 不做商机、阶段、销售管道、交接工作流。

## 1. 两个对象

| 对象 | 一条记录代表 | 怎么用 |
|---|---|---|
| **客户**（People 改名） | 一个客户 | 存联系方式、负责人、状态、提醒 |
| **沟通记录**（自定义） | 一轮沟通 | 在客户页的“沟通记录”里添加，按时间线查看 |

侧边栏只保留“客户”；沟通记录从客户详情页进入，不单独放在侧边栏。

## 2. 客户字段

标准字段：姓名、手机（可选）、邮箱（可选）。

自定义字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| 微信号 | 文本 | 客户微信/企微号 |
| 来源渠道 | 单选 | 抖音 / 小红书 / 视频号 / 微信 / 转介绍 / 线下 / 官网 / 其他 |
| 当前负责人 | 单选 | 员工A / B / C / D（改成真实姓名） |
| 客户状态 | 单选 | 新客户 / 跟进中 / 已成交 / 流失 |
| 当前轮次 | 数字 | 1 / 2 / 3 / 4… |
| 下次提醒日期 | 日期 | 几天后提醒 |
| 提醒内容 | 文本 | 例如“再次联系客户，确认报价” |
| 提醒状态 | 单选 | 待联系 / 已联系 |
| 最后沟通时间 | 日期时间 | 最近一次联系时间 |
| 备注 | 长文本 | 客户背景、偏好、禁忌 |

## 3. 沟通记录字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 名称 | 文本 | 建议填“第N轮” |
| 关联客户 | 关系 → 客户 | 必填；从客户页添加时会自动关联 |
| 轮次 | 数字 | 1 / 2 / 3… |
| 沟通时间 | 日期时间 | 实际沟通时间 |
| 沟通人 | 单选 | 员工A / B / C / D |
| 沟通内容 | 长文本 | 客户说了什么、顾虑、下一步 |
| 本轮结果 | 单选 | 继续跟进 / 待报价 / 已成交 / 流失 / 暂缓 |

其他字段（关联商机、渠道、客户反馈、意向等级、附件）已隐藏，保持表单简单。

## 4. 视图

| 视图 | 筛选 | 排序 | 用途 |
|---|---|---|---|
| **我的客户-员工A/B/C/D** | 当前负责人 = 员工X | 下次提醒日期从早到晚 | 每个人看自己的客户 |
| **待联系** | 提醒状态 = 待联系 | 下次提醒日期从早到晚 | 每天上班先看这个 |
| **全部客户**（默认） | 无 | 创建时间从新到旧 | 主管看全部 |

> 当前负责人选项还是“员工A/B/C/D”。把选项改成 4 位同事的真实名字即可；视图会自动跟着选项值走，不用改筛选。视图名称也可以改成“我的客户-张三”等。

## 5. 每天怎么用

### 新建客户 + 第 1 轮

1. 客户 → 创建：填姓名、微信号、来源渠道；当前负责人选 A。
2. 打开客户 → “沟通记录” → 添加：名称“第1轮”、轮次 1、沟通时间、沟通人 A、沟通内容、本轮结果。
3. 回到客户字段：当前轮次=1；最后沟通时间=今天；下次提醒日期=3 天后；提醒内容写清楚要做什么；提醒状态=待联系。

### 交接给 B

1. 客户字段：当前负责人从 A 改成 B。
2. B 打开“我的客户-员工B”，就能看到这个客户和全部沟通记录。
3. 不需要工作流，也不需要改其他字段。

### B 持续跟进

1. 打开客户，先看“沟通记录”里的历史。
2. 联系完：
   - 提醒状态 = 已联系
   - 新增一条沟通记录：轮次 2、沟通时间、沟通人 B、内容、结果
   - 当前轮次 = 2
   - 最后沟通时间 = 今天
   - 下次提醒日期 + 提醒内容
   - 提醒状态改回 **待联系**
3. 第 3、4 轮重复。
4. 成交：客户状态=已成交；流失：客户状态=流失。

### 每天提醒

打开“待联系”视图，按日期从早到晚看：

- 日期是今天或更早 → 今天要联系
- 点开客户 → 看提醒内容和沟通历史
- 联系完按上面的步骤更新

## 6. 规则

- **一个客户一条记录**：不要给同一个人建多条客户。
- **聊一次一条沟通记录**：不要把所有轮次写进一个字段。
- **提醒只认客户上的“下次提醒日期”+“提醒状态”**。
- **交接只改“当前负责人”**，B 在自己的视图里就能看到。
- **手机可选**：如果提示“输入有效的电话号码”，先选国家 China (+86)，再输入 11 位手机号；不想填就留空，用微信号联系。

## 7. 已撤掉的东西

- 商机、阶段、销售管道、二轮以上未成交等视图
- 交接工作流
- 公司、任务、备注、仪表板、营销活动（对象已隐藏）
- 旧的“线索池/渠道分析/我的待跟进/今日已约/沟通流水”视图

当前客户和沟通记录都是 0 条，从第一个真实客户开始即可。

## 8. 一页纸

> 一个客户一条，聊一次一条，提醒放客户，交接改负责人，联系完改状态。
